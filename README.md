# Nikasa 🚀

Nikasa is a business portfolio web application for showcasing web app and Android app development services, built with Angular.

## Features

- Modern business portfolio UI
- Responsive design
- Service showcase
- Project showcase
- Contact section
- Mobile-friendly layout
- Fast performance

## Tech Stack

- Angular
- TypeScript
- HTML
- CSS
